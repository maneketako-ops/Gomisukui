# some-water-project

**お風呂のゴミすくい** — 湯船に浮いたゴミを手ですくって集める three.js のゲームです。
水の波・流れ・すくった水は物理シミュレーションで動いていて、慌てて手を動かすと波や流れでゴミが逃げていきます。

## 動かし方

```bash
npm install
npm run dev      # http://localhost:5173 を開く（同じネットワークのスマホからも開けます）
npm run build    # dist/ に静的ファイルを出力（どこにでも置ける）
npm test         # 物理とゲーム進行のテスト
```

## 公開（GitHub Pages）

`main` に入った変更は GitHub Actions（`.github/workflows/deploy.yml`）でテスト・ビルドされ、GitHub Pages に公開されます。
最初に一度だけ、リポジトリで次の設定をしてください。

1. Settings → General の一番下で、リポジトリを **Public** にする（無料プランの Pages は公開リポジトリのみ）
2. Settings → Pages の **Source** を **GitHub Actions** にする
3. `main` へマージする（または Actions タブから「Deploy to GitHub Pages」を手動実行）

公開先は `https://<アカウント名>.github.io/<リポジトリ名>/` です（URL は Actions が自動で設定します）。
X などに URL を貼ると、`public/og.png` の画像つきカードで表示されます（OGP）。
別の場所で公開する場合は、ビルド時に環境変数 `VITE_SITE_URL`（末尾 `/` つき）で公開 URL を指定してください。
カードの画像やシェアボタンの URL に使われます。

### SNS 向けの機能

- 結果画面の「結果をポスト」で、点数・ランク・逃げられた回数とハッシュタグ `#お風呂のゴミすくい` 入りの投稿画面を開きます。
  スマホでは「ほかのアプリで共有」（LINE など）も使えます。
- 画質は「自動」が初期設定です。動きが重い（40 fps を下回り続ける）と、自動で「中」「低」へ下げてお知らせします。
  タイトル画面の「画質」ボタンで、自動・高・中・低を切り替えられます（ブラウザに保存）。
  「低」では解像度・影・集光模様の更新・粒子の水の描画を軽くし、水の流れの計算を 1 フレームおきにします。

## 遊び方

制限時間 75 秒で、浮いている 12 個のゴミをできるだけ多くすくいます。

1. ゴミの真下で手を沈める（近づくときに速く動かすと、押しのけた水でゴミが逃げる）
2. そのまま持ち上げると、手のひらのくぼみにゴミが乗る
3. 手のひらの水が指のすき間から抜けきって、ゴミの周りの輪っかが満ちるまで耐えると回収

手に乗ったあとも油断できません。抜けていく水の流れや「ザッ」と寄せる波、手を動かしたときの慣性で、
ゴミは手のひらの上を滑ります。低い手首側の縁を越えたり、髪の毛や糸くずが指のすき間をすり抜けたりすると、
真ん中でとらえていても「スルッ」と逃げます（真ん中でとらえても 3 回に 1 回くらい）。

| ゴミ | 点数 |
| --- | --- |
| 髪の毛 | 30 |
| 糸くず | 20 |
| 木くず | 15 |
| 葉っぱ | 10 |

一度のすくいで複数回収すると、それぞれの点数が個数倍になります。全部すくうと残り時間 1 秒につき 5 点のボーナス。ベストスコアはブラウザに保存されます。

### 操作

| | パソコン | スマホ |
| --- | --- | --- |
| 手を動かす | マウスを動かす | 画面をなぞる（手は指の少し上に来る） |
| 沈める | 左クリックか Space を押している間 | 右下の「すくう」ボタンを押している間 |
| すくう | 離す（手が持ち上がる） | ボタンを離す |
| やめる | Esc / 「やめる」 | 「やめる」 |

タイトルの「自由に遊ぶ」では、ゲームなしで水と遊べます（手の形の切り替え `1`〜`4`、傾ける `T`、蛇口 `F`、リセット `R`、高さ `Q`/`E`、向き `Z`/`X`、右ドラッグ・2 本指で視点）。

## 水の物理モデル

水面はいくつかの現象を組み合わせて計算しています（`src/sim/`）。

- **体積の保存**（`waterSim.js`）
  水位は「浴槽内の水量 + 手が水中で押しのけている体積」から厳密に決まります。手を沈めると水位が上がり、すくった水・しずく・蛇口の水も 1 粒ずつ体積として出し入れされます。
- **分散性のある波**（`waterSim.js`）
  本物の水の波は波長によって速さが違います（ω² = (g·k + σ/ρ·k³)·tanh(k·H)）。
  波の源をガウシアンピラミッドで 6 つの波長帯に分け、帯ごとに対応する位相速度で波動方程式を解くことで、
  小さなさざ波はゆっくり、大きなうねりは速く広がり、手を動かすと航跡のような模様ができます。
  壁はノイマン境界なので波が反射し、急すぎる波は砕けて（振幅が頭打ちになり）泡になります。
- **流れと渦**（`flowSim.js`）
  表層の 2D 非圧縮流（MAC グリッド、MacCormack 移流、圧力投影）。手の抗力で水が引きずられ、かき混ぜると渦が残ります。
  移流から生じる圧力（遠心力）で渦の中心がわずかにくぼみます。
- **手と水面の相互作用**（`coupling.js`）
  手の形をカプセルの集まりとして、水面の各セルで「水中にある手の区間」を求めます。
  押しのけた体積の変化が波を起こし（深いところの動きほど水面への影響は小さい）、水面を貫いている部分は波をさえぎります。
- **粒子の水**（`fluidSim.js`）
  手ですくった水、こぼれる水、しずく、蛇口の水流は Position Based Fluids（PBF）で計算します。
  手が水面を抜けるとき、手のくぼみに囲まれていた水だけが粒子になり、水面に落ちると体積・運動量・泡・波紋として戻ります。

## 描画

- 手は骨格に沿った先細りカプセルを滑らかに結合した SDF から Surface Nets でメッシュを作り、21 本の骨でスキニングしています（`src/hand/`）。同じカプセルが物理の当たり判定にもなります。
- 水面は画面空間の屈折（水中の光路長に応じた吸収・散乱）、浴室を撮ったキューブマップによるフレネル反射、泡を描きます。
- 浴槽の底には水面の法線から計算した集光模様（コースティクス）が落ちます。
- 粒子の水は「深度 → バイラテラルフィルタ → 法線の復元」による画面空間流体レンダリングで、つながった水として描きます。

## 構成

```
src/
  main.js                 シーン・入力・画面の切り替え・シェア・ループ
  quality.js              画質の段階と自動調整
  game/debris.js          浮かぶゴミ（漂流・手に乗る・回収の判定）
  game/game.js            ゲーム進行（タイマー・得点・コンボ・結果）
  game/fx.js              演出（光のはじけ・しゃぼん玉・湯気）
  game/sfx.js             効果音（WebAudio で合成）
  config.js               寸法・定数
  sim/waterSim.js         水位・分散性の波・泡
  sim/flowSim.js          2D 非圧縮流
  sim/fluidSim.js         PBF 粒子
  sim/coupling.js         手 ⇄ 水面 ⇄ 粒子
  hand/handModel.js       手のモデル（SDF・スキニング・コライダー）
  hand/surfaceNets.js     SDF のメッシュ化
  hand/handController.js  手の形と動き
  scene/bathroom.js       浴室・浴槽・蛇口・照明
  scene/duck.js           浮かぶアヒル
  render/                 水面・コースティクス・粒子の水・描画パス
public/                  SNS カード画像（og.png）・アイコン
.github/workflows/        GitHub Pages への自動公開
test/sim.test.js          物理とゲームのテスト（体積保存・安定性・分散性・渦・すくう・回収）
```
